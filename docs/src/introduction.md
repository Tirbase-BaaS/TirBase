# TirBase Documentation

TirBase is an offline-first, local-first edge runtime and BaaS core designed to
make critical edge nodes **safe to command, safe to update, and able to run
autonomously**.

This mdBook site (CLAIM-50.1, PV-17.2) provides:

- Architecture overview
- Threat model summary and references
- Operator guide
- Deployment hardening guidance
- Per-vertical demo pages
- Public API, configuration, and operational procedure references

For the authoritative claim/test mapping, see [`CLAIMS.md`](../../CLAIMS.md).
For detailed subsystem design, see the project design and requirements documents
under `.kiro/specs/tirbase-master-enhancement/`.
