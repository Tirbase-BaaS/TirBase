## Residual blockers (evidence-backed, genuinely hardware/environment-gated or out-of-scope for CI proof)

- **Physical transport/radio paths:** BLE/LoRa/Iridium drivers, RF duty-cycle behavior, and true multi-hop radio topologies are not exercised by loopback CI; loopback Swarm/TCP proofs cover the production mesh/merge/quorum/saturate/contamination logic exercised in software.
- **Anchor-attested location hardware:** optional `Anchor_Attested_Location` mode requires fixed beacon hardware/cryptographic location tokens and is not CI-proven.
- **Scale/performance limits:** 100k outbound queue capacity, 10-second LOW-queue clearing under sustained load, and long-duration bandwidth-floor measurements are not load-benchmarked in CI; scheduler/queue logic is unit/property-tested.
- **SDK browser end-to-end in CI:** `tirbase-sdk` real-WASM/Jest e2e requires local build artifacts/tooling; gateway-admin SDK e2e requires built gateway binary. These are required local verification commands for WS8 handoff (record results in STATUS).
