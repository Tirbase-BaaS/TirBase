# Customer DPIA templates

Complete one template per domain in scope. The open baseline assessments are at
`docs/compliance/venue-dpia/`; these templates add the customer-specific facts
that TirBase cannot supply: lawful basis, notices, roles, jurisdiction,
transfers, camera/VMS facts and sign-off.

Do not copy the baseline as a completed customer DPIA. A customer pilot requires
the customer's DPO/legal reviewer to complete, sign and date the record in
`../review/privacy-review-record.md`.

| Template | Use when |
|---|---|
| `ticket.md` | ticket scanning/admission data is processed |
| `credential.md` | gate credentials are issued, verified or revoked |
| `cctv.md` | CCTV **metadata** is correlated; add a separate VMS/video DPIA if video is used |
| `access.md` | gate decisions or operator attribution are recorded |
